The 4 types of metadata

Metadata = data about data, stored inside every photo file

Exam answerDescriptive, Administrative, Technical, Processing
DescriptiveWhat's IN the photo?
  • Keywords
  • Caption, title
  • Location, people
AdministrativeWho OWNS it?
  • Copyright ©
  • Creator name
  • Contact, usage rights
TechnicalHow did the CAMERA take it?
  • Shutter, aperture, ISO
  • Camera and lens
  • Date and time (EXIF)
ProcessingWhat EDITS were made?
  • Exposure, contrast
  • Crop, white balance
  • Lightroom edit history
💡
D-A-T-P: "Dogs Always Take Pictures." Spelling counts on the exam: technical, not "technial".

03

The 3‑2‑1 backup rule

The standard way to never lose your photos

Exam answer3 copies, 2 different media, 1 offsite
3
copies

The original plus 2 backups.

2
different media

For example, the computer's drive plus an external hard drive, so one problem can't wipe out both.

1
offsite

Stored somewhere else, like the cloud or a drive at a family member's house.

If you skip…What can go wrong
3 copiesOne drive dies and there's no other copy.
2 mediaDrives of the same type can fail the same way.
1 offsiteA fire, flood or theft at home destroys every copy at once.
💡
Count down 3 → 2 → 1: 3 copies, on 2 types, 1 far away. Spelling: copies (one "p").
04

JBOD vs RAID

Two ways to use several hard drives together

Exam answerJBOD (Just a Bunch Of Disks): disks work independently with no backup, so if one fails you lose its data. RAID (Redundant Array of Independent Disks): the same data is stored on multiple disks, so if one fails the data is still safe.

💡
RAID = Redundant = Replacement copy. JBOD = "just a bunch," with no safety net. (Beyond class: RAID 1, mirroring, is the backup type. RAID 0 is for speed and has no backup.)
05

Archive vs backup

The difference is whether you're still working on the files

BackupFiles you're CURRENTLY working on
  • A safety copy in case something breaks
  • Updated often as your work changes
  • Example: this week's shoot you're still editing
ArchiveFiles you're NO LONGER working on
  • Long-term storage of finished work
  • Rarely changes, and frees up space
  • Example: last year's finished wedding photos
💡
Backup watches your back right now. An archive is like a museum for finished work.
