01

Archiving isn't just a file format

Should you convert to DNG?

preservation = redundancy + documentation + validation + migration plan

Redundancy

Several copies, for example a RAID (redundant array of independent disks). Put it behind a surge protector.

Documentation & validation

A README with your naming convention. Run a checksum to prove each copy matches.

Migration plan

Move files off dying media before you can't read them (floppies, old disks, CDs).

DNG today: version 1.7.1. Adobe keeps the DNG SDK (software development kit) available. DNG was originally lossless, but lossy DNG has been possible since Lightroom 4, and DNG is popular on smartphones with raw capture, and it defeats much of the point of raw.

02

The processing chain

From photons to a file

  • White balance in raw is read from the metadata and applied, not baked in. Shot under fluorescent with the camera set to tungsten? Fix it in Camera Raw with no loss.
  • Tone mapping ≈ the gamma curve. A sensor is linear (twice the photons = twice the signal), which is good for science. Our vision isn't linear, so photos get a tone curve to look natural.
  • You can render one raw many ways: TIFF, JPEG, HEIF, PSD…
03

TIFF

Tagged Image File Format

  • Created by Aldus in 1986, owned by Adobe since 1994. Originally made for scanners and desktop publishing.
  • Flexible raster format: grayscale, RGB, CMYK, CIELAB, indexed color; 8, 16 or 32 bits per channel; layers; alpha channels.
  • Compression: none, lossless, or lossy, your choice.
  • Classic TIFF uses 32-bit offsets, so the max is 4 GB. BigTIFF uses 64-bit offsets for bigger files (scientific and medical images).
Beyond the lectureIn class: Adobe charges a licensing fee, so not every program offers TIFF (use that on the exam). For reference, the TIFF 6.0 specification itself is published openly.
04

JPEG

Joint Photographic Experts Group

★ Her test pick · Test question
What happens when you edit and re-save a JPEG over and over?
Generational degradation: it's compressed again every save, so artifacts build up.
★ Her test pick · Test question (the chart)
TIFF vs JPEG: which is better for repeated editing, and which allows transparency?
TIFF for both. JPEG degrades every save and has no transparency.
  • JPEG is both a file format and a lossy compression method. Lossy = data thrown away is gone.
  • 8 bits per channel only. Can embed a color profile. Small files (about 500 KB – 8 MB). .jpg = .jpeg. Designed for efficient distribution.
  • Generational degradation: every re-save compresses an already compressed file, and artifacts pile up fast. Editing a JPEG? Save it as TIFF or PSD first.
  • In-camera JPEG: white balance, tone, color, sharpening, noise reduction and compression are baked in. Get it right in camera (custom white balance, User 1/User 2 settings).

06

How compression works

Images are full of redundancy

Lossless

Smaller file, and decompressing gives back the exact original. Nothing wrong with it.

Lossy

Throws away data it thinks you won't see. You get back an approximation, not the original.

Statistical

Repeated values: store "red ×4, blue ×7, green ×2" instead of 13 separate pixels.

Interpixel / spatial

Neighbors are similar. Store 100 and then the differences: 100, +1, 0, +2, +1, 0. Lossy: just call them all 100.

Psychovisual

We're easy to fool. Drop what the eye barely sees: fine detail, small color changes, contrast we can't notice.

How a JPEG is made

Y = brightness, Cb = blue–yellow, Cr = red–green. We see brightness much better than color, so cutting the color channels in half already saves lots of space.

07

Compression artifacts

Use the right words

Compression changes FILE SIZE, not RESOLUTION

Example: 600 × 800 px TIFF = 1.5 MB. Same 600 × 800 px JPEG = 119 KB.

Blocking

The 8 × 8 blocks become visible because variation inside each block was squeezed out.

Posterization / banding

Smooth tones become steps because there are too few tonal levels. (Class: "exclusively a JPEG artifact".)

Ringing & detail loss

Halos next to edges, fine texture smoothed away, color errors, soft edges.

Aliasing

A sampling problem: detail too fine for the pixels gives moiré, false detail and color artifacts. Not only JPEG: downsampling causes it too.

Stair-stepping

Diagonal edges turn into steps. Say "stair-stepping", not "jaggies" (sounds amateur).

Pixelation = NOT an artifact

Zooming to 3200% just magnifies pixels. That's magnification, not damage.

Beyond the lectureOn the exam, use "posterization is a JPEG artifact". In practice, banding can also appear when an 8-bit image is pushed hard in editing. That's one more reason to edit at 16 bits.

See aliasing (moiré) happen

Fine rings sampled with enough pixels look right. Lower the pixels and false patterns (moiré) appear that aren't really there.

08

Parametric editing & virtual copies

One original, many versions

  • Edits are saved as instructions, so you can change your mind, try alternative looks, sync settings across many images, revisit old edits and export several versions.
  • A virtual copy is another set of instructions on the same original. You can have a black and white version, a warm version and a masked version without filling your hard drive.

Rendering engine: one source, many interpretations

Her slide: one source file can produce many interpretations without creating multiple RAW originals. Each version is just a set of instructions (a virtual copy).
